MECHANISM (per user gate decision, revised -- NOT per-AMS-own-production):
  1. ASEAN total gas = SUM of every AMS 2023 production.
  2. +20% for imports  ->  regional envelope = 1.2 x ASEAN-total-production.
  3. Split into a UNIFORM cap across the region: every AMS region node carries
     the SAME cap value. This deliberately avoids choking the import-dependent
     nations (e.g. Singapore produces ~0 but must still be able to run gas
     plant on imported LNG, so it gets the same headroom as a producer).
  4. Time shape: FLAT, 2023-anchored (held constant 2025->2060), not declining.
  5. Scenario: RAS ONLY (Regional Aspiration Scenario). Do NOT inherit into
     Current Accounts / Baseline / ATS.
